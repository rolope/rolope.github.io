FlowsJS: running JavaScript bots on live WhatsApp traffic

2022–2025 · Soriana · Estafeta

The problem

Bots were written in JavaScript, but the platform was .NET and message-driven. The company needed a service that runs bot scripts safely on live WhatsApp traffic, scales with demand, and lets bot developers ship without redeploying the service.

What I built

  • Kicked off the service (first PR: new name and new protocol) and ran its develop → rc → master release train through its first year.
  • Bot scripts and text resources load from the platform hub; split ~10k lines of bot libraries into a versioned npm package.
  • Set up SonarCloud, moved production to a new AWS Fargate cluster and added BlazeMeter load tests for Soriana to CI.
  • Idle jobs (timeouts and delayed messages), multimedia, instant messages, cached AWS signed URLs and OCR integration.
  • Introduced BDD/TDD with SpecFlow and Coverlet.
  • Bot-to-bot handoff that keeps metrics and history on the receiving bot, so Estafeta could A/B test bots; feature flags with percentage rollouts.

My role

Led the service's launch and first year; third-largest contributor overall. Its production instances on Kubernetes autoscale from 5 to 30 replicas.

Stack

  • .NET 5
  • V8
  • RabbitMQ
  • Redis
  • MongoDB / DocumentDB
  • AWS Fargate
  • Kubernetes / Helm
  • SonarCloud
  • BlazeMeter
  • SpecFlow
