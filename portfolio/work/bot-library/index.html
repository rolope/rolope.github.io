@auronix/build-core: the library behind ~219 WhatsApp bots

2022–2026 · Auronix platform

The problem

Hundreds of client bots, for banks, retailers and logistics companies, needed the same WhatsApp building blocks: navigation, memory, menus, forms, carts and flags. Every new WhatsApp capability from Meta had to reach all of them without each team reimplementing it.

What I built

  • Created the WhatsAppFlows module (2023): any bot can open native in-chat forms; later added multiple-choice answers, image/video/document headers and configurable tokens.
  • Created the FeatureFlag module (2024) on GitLab feature flags, with percentage rollouts and unit tests, so bot behavior can change without redeploying.
  • Main contributor to WhatsApp Cart: catalog sets, order detection, store search, related products and pacing for promotional multi-product messages.
  • Core messaging behaviors: invalid-answer handling, consecutive and instant behaviors, HTTP timeouts, retries, footers and handover to human agents.
  • Lists, CTA URL buttons, language resources (i18n) and millisecond idle timeouts, with unit tests alongside each change.

My role

Core contributor from 2022 to 2026. I didn't create the library, but I created two of its modules and was one of its top human contributors. About 219 bots across three repositories import it.

Stack

  • TypeScript types
  • Jest

  • GitLab CI
  • SonarQube
