Larii: an offline-first household organizer

2026 · Freelance

The problem

A family wanted one place to share the household's mental load (calendar, cleaning, maintenance, menus, shopping and finances) with different permissions for family members and household staff, usable offline on any phone.

What I built

  • Installable, offline-first web app on Firebase (Auth, Firestore, Storage, App Check, Hosting) with no build step.
  • Passwordless email-link sign-in, invitations and per-household data isolation.
  • Three roles (admin, family, staff) with per-section permissions enforced in Firestore and Storage security rules and mirrored in the UI.
  • Automated security-rules tests in the Firestore emulator; deploys are blocked if any test fails.
  • Sections: Today summary, Agenda with repeating events, Cleaning by room and frequency, Maintenance, Menus, Shopping and Finances.
  • A data-import tool to seed a household from a JSON file.

My role

Sole developer on a fixed-scope freelance MVP, from the client's spec to deployment.

Stack

  • Firebase
  • Firestore rules
  • JavaScript
  • Service worker / PWA
  • Node test runner
